# AFFiNE Research

## Strengths

- Excellent UX
- Infinite whiteboard
- Databases
- Local-first support

## Weaknesses

- Workspace becomes the source of truth.
- Requires importing/creating data inside AFFiNE.

## Ideas to Adopt

- Infinite canvas
- Block editing
- Multiple synchronized views

## Ideas to Reject

- Internal database replacing the filesystem.
